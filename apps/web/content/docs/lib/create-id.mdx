`createId` generates compact, URL-safe identifiers with entropy from the current time, a counter, a runtime fingerprint, and random salt.

It is intended for application identifiers where you want a short generated string without depending on a separate ID package.

## Usage

```tsx
import { createId } from '@/lib/create-id'

const id = createId()

console.log(id)
// Example: c8f0g3...
```

The generated identifier always starts with `c` and is derived from multiple changing inputs rather than a single random call.

## Randomness

The generator uses `crypto.getRandomValues` when the runtime exposes it and falls back to `Math.random` when it does not.

You can pass a custom random function for deterministic tests:

```tsx
const id = createId(() => 0.5)
```

A deterministic random function is useful only for tests; do not use one for production IDs.


## API Reference

### `createId`

```ts
function createId(rand?: () => number): string
```

| Parameter | Description |
| --- | --- |
| `rand` | Optional random source used by the generator. Defaults to the best available runtime random source. |

The current implementation combines a base-36 timestamp, counter entropy, runtime fingerprint, and additional random salt before hashing with SHA3-512.
