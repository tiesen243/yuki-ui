The native `Button` is a pressable control built on React Native's `Pressable`. It reuses the shadcn/ui button variant definitions and adds native interaction behavior.

Button text is automatically rendered with the native `Typography` component, so string children inherit the appropriate text color for the selected button variant.

See the [shadcn/ui Button documentation](https://ui.shadcn.com/docs/components/base/button) for the original component API and additional examples.

## Usage

```tsx
import { Button } from '@/components/native/button'

export function Example() {
  return (
    <Button onPress={() => console.log('Pressed')}>
      Continue
    </Button>
  )
}
```

### Variants

Use `variant` to communicate the action's importance.

```tsx
<Button variant='default'>Continue</Button>
<Button variant='secondary'>Secondary</Button>
<Button variant='outline'>Cancel</Button>
<Button variant='ghost'>More</Button>
<Button variant='destructive'>Delete</Button>
<Button variant='success'>Saved</Button>
<Button variant='info'>Learn more</Button>
<Button variant='warning'>Review</Button>
<Button variant='link'>View details</Button>
```

### Sizes

Use the `size` prop from the shared button variant definition.

```tsx
<Button size='default'>Default</Button>
<Button size='sm'>Small</Button>
<Button size='lg'>Large</Button>
```

Use the sizes supported by the button implementation in your project. Because the native component re-exports `buttonVariants`, the same variant definition can also be reused when creating related controls.

### Disabled state

React Native's `Pressable` disabled behavior is passed through directly.

```tsx
<Button disabled>
  Continue
</Button>
```

### Custom content

String children are wrapped in `Typography`. For icons or more complex layouts, pass React nodes directly.

```tsx
<Button>
  <Icon className='size-4' />
  <Typography>Continue</Typography>
</Button>
```

## Interaction

The native implementation adds `active:opacity-80` to the button styles, providing visual feedback while the button is pressed.

All normal `Pressable` props remain available, including:

```tsx
<Button
  onPress={handlePress}
  onLongPress={handleLongPress}
  disabled={loading}
  hitSlop={8}
>
  Save
</Button>
```

## Typography inheritance

When the child is a string, `Button` renders it through `Typography` and supplies a context class based on the button variant. This keeps text color synchronized with the button background.

For custom children, you are responsible for choosing the appropriate icon/text styling.

## API reference

### `Button`

`Button` combines `Pressable` props with the shared `buttonVariants` props.

| Prop | Description |
| --- | --- |
| `variant` | Button visual variant. |
| `size` | Button size variant. |
| `children` | String or React content. |
| `className` | Additional NativeWind classes. |
| `onPress` | Called when the button is pressed. |
| `disabled` | Prevents interaction when true. |
| `...props` | Other supported `Pressable` props. |

<Callout>

For text-only buttons, pass a string and let `Button` render the `Typography` wrapper automatically. For icon or compound content, render the content yourself.

</Callout>
