The native `Separator` component renders a one-pixel divider using React Native's `View`. It can be oriented horizontally or vertically and is useful for list sections, cards, settings screens, and grouped content.

See the [shadcn/ui Separator documentation](https://ui.shadcn.com/docs/components/base/separator) for the original component API and additional examples.

## Usage

The default orientation is horizontal.

```tsx
<View className='gap-4'>
  <Typography>Account</Typography>
  <Separator />
  <Typography>Security</Typography>
</View>
```

### Vertical separator

Use `orientation='vertical'` when separating items in a row.

```tsx
<View className='h-6 flex-row items-center gap-3'>
  <Typography>Home</Typography>
  <Separator orientation='vertical' />
  <Typography>Settings</Typography>
</View>
```

### Custom styling

```tsx
<Separator className='bg-primary' />
```

For vertical separators, the component uses `self-stretch` so the divider follows the height of its parent.

## Orientation

```tsx
<Separator orientation='horizontal' />
<Separator orientation='vertical' />
```

The horizontal variant uses `h-px w-full`. The vertical variant uses `w-px self-stretch`.

## API reference

| Prop | Default | Description |
| --- | --- | --- |
| `orientation` | `horizontal` | Either `horizontal` or `vertical`. |
| `className` | — | Additional NativeWind classes. |
| `...props` | — | React Native `View` props. |

<Callout>

For a vertical separator, make sure the parent has a meaningful height. The component uses `self-stretch` rather than an explicit height.

</Callout>
