`Typography` is the shared text primitive for the web registry. It centralizes semantic text variants while still allowing the rendered element to be overridden with the `as` prop.

The variant controls both styling and, by default, the element rendered to the DOM.

## Usage

```tsx
import { Typography } from '@/components/ui/typography'

export function TypographyExample() {
  return (
    <div className='space-y-2'>
      <Typography variant='h1'>Account settings</Typography>
      <Typography>Update your profile and notification preferences.</Typography>
    </div>
  )
}
```

## Variants

The shared variant map contains headings, paragraph text, list styles, quotes, code, and captions:

```tsx
<Typography variant='h1'>Heading 1</Typography>
<Typography variant='h2'>Heading 2</Typography>
<Typography variant='h3'>Heading 3</Typography>
<Typography variant='h4'>Heading 4</Typography>
<Typography variant='p'>Paragraph</Typography>
<Typography variant='small'>Small</Typography>
<Typography variant='ul'>List</Typography>
<Typography variant='ol'>Ordered list</Typography>
<Typography variant='blockquote'>Quote</Typography>
<Typography variant='code'>Code</Typography>
<Typography variant='caption'>Caption</Typography>
```

## Changing the rendered element

The component normally renders the element implied by `variant`. Use `as` when you need the styling of one variant with another semantic element:

```tsx
<Typography variant='h2' as='div'>
  Non-heading layout text
</Typography>
```

## Class merging

`className` is merged after the variant classes, so local styles can override the base typography classes.

## API Reference

### `Typography`

| Prop        | Type                                                                                                    | Default |
| ----------- | ------------------------------------------------------------------------------------------------------- | ------- |
| `variant`   | `'h1' \| 'h2' \| 'h3' \| 'h4' \| 'p' \| 'small' \| 'ul' \| 'ol' \| 'blockquote' \| 'code' \| 'caption'` | `'p'`   |
| `as`        | `React.ElementType`                                                                                     | variant |
| `className` | `string`                                                                                                | —       |
| `...props`  | `React.ComponentProps<'p'>`                                                                             | —       |

### `typographyVariants`

The exported CVA helper used by `Typography`:

```ts
typographyVariants(props?: VariantProps<typeof typographyVariants>)
```
