The native `RadioGroup` provides a mutually exclusive set of options. It stores the selected value in context and exposes each option through `RadioGroupItem`.

The implementation supports both controlled and uncontrolled state and maps its state to React Native accessibility roles.

See the [shadcn/ui Radio Group documentation](https://ui.shadcn.com/docs/components/base/radio-group) for the original component API and additional examples.

## Usage

```tsx
import {
  RadioGroup,
  RadioGroupItem,
} from '@/components/native/radio-group'

export function Example() {
  return (
    <RadioGroup>
      <RadioGroupItem value='comfortable'>
        <Typography>Comfortable</Typography>
      </RadioGroupItem>

      <RadioGroupItem value='compact'>
        <Typography>Compact</Typography>
      </RadioGroupItem>
    </RadioGroup>
  )
}
```

### Default selection

The native implementation does not expose a separate `defaultValue` prop. For an uncontrolled group, initialize it by passing `value` without an `onValueChange` handler.

```tsx
<RadioGroup value='comfortable'>
  <RadioGroupItem value='comfortable'>
    <Typography>Comfortable</Typography>
  </RadioGroupItem>

  <RadioGroupItem value='compact'>
    <Typography>Compact</Typography>
  </RadioGroupItem>
</RadioGroup>
```

The group owns the subsequent selection changes.

### Controlled state

Provide both `value` and `onValueChange` when the parent owns the selected value.

```tsx
const [value, setValue] = React.useState('comfortable')

return (
  <RadioGroup
    value={value}
    onValueChange={setValue}
  >
    <RadioGroupItem value='comfortable'>
      <Typography>Comfortable</Typography>
    </RadioGroupItem>

    <RadioGroupItem value='compact'>
      <Typography>Compact</Typography>
    </RadioGroupItem>
  </RadioGroup>
)
```

### Disabled option

```tsx
<RadioGroupItem value='enterprise' disabled>
  <Typography>Enterprise</Typography>
</RadioGroupItem>
```

Disabled options cannot change the selected value and are rendered with reduced opacity.

## Accessibility

The group uses:

```text
accessibilityRole="radiogroup"
```

Each option uses:

```text
accessibilityRole="radio"
accessibilityState={{ checked, disabled }}
aria-checked={checked}
aria-disabled={disabled}
```

The selected option is represented by the inner indicator.

## API reference

### `RadioGroup`

| Prop | Description |
| --- | --- |
| `value` | Selected value. |
| `onValueChange` | Called when an item becomes selected. |
| `className` | Additional classes. |
| `...props` | React Native `View` props. |

### `RadioGroupItem`

| Prop | Description |
| --- | --- |
| `value` | Unique value represented by the option. |
| `disabled` | Prevents selecting the option. |
| `activeOpacity` | Touch feedback opacity. |
| `onPress` | Native press callback. |
| `children` | Label/content for the option. |
| `className` | Additional classes. |
| `...props` | React Native `TouchableOpacity` props. |

<Callout>

Every `RadioGroupItem` must be rendered inside a `RadioGroup`. The item reads and updates its selected value through the group's context.

</Callout>
