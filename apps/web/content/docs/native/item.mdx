The native `Item` component is a composable list-row primitive for settings screens, menus, notifications, and other collection-based interfaces.

Instead of forcing a fixed row structure, it provides primitives for media, content, actions, headers, footers, titles, descriptions, and separators.

See the [shadcn/ui Item documentation](https://ui.shadcn.com/docs/components/base/item) for the original component API and additional examples.

## Usage

```tsx
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemTitle,
} from '@/components/native/item'
import { Button } from '@/components/native/button'

export function Example() {
  return (
    <Item>
      <ItemContent>
        <ItemTitle>Notifications</ItemTitle>
        <ItemDescription>
          Receive updates about your account.
        </ItemDescription>
      </ItemContent>

      <ItemActions>
        <Button size='sm' variant='ghost'>Manage</Button>
      </ItemActions>
    </Item>
  )
}
```

### Media

Use `ItemMedia` for icons, avatars, or images.

```tsx
<Item>
  <ItemMedia variant='icon'>
    <BellIcon className='size-4' />
  </ItemMedia>

  <ItemContent>
    <ItemTitle>Notifications</ItemTitle>
    <ItemDescription>Receive account updates.</ItemDescription>
  </ItemContent>
</Item>
```

For images:

```tsx
<Item>
  <ItemMedia variant='image'>
    <Image source={{ uri: user.avatar }} />
  </ItemMedia>

  <ItemContent>
    <ItemTitle>{user.name}</ItemTitle>
    <ItemDescription>{user.email}</ItemDescription>
  </ItemContent>
</Item>
```

### Variants and sizes

```tsx
<Item variant='default'>...</Item>
<Item variant='outline'>...</Item>
<Item variant='muted'>...</Item>

<Item size='default'>...</Item>
<Item size='sm'>...</Item>
<Item size='xs'>...</Item>
```

The variants control the border/background treatment, while size controls padding and spacing.

### Groups

Use `ItemGroup` to organize several items.

```tsx
<ItemGroup>
  <Item>
    <ItemContent>
      <ItemTitle>General</ItemTitle>
    </ItemContent>
  </Item>

  <ItemSeparator />

  <Item>
    <ItemContent>
      <ItemTitle>Privacy</ItemTitle>
    </ItemContent>
  </Item>
</ItemGroup>
```

### Headers and footers

`ItemHeader` and `ItemFooter` span the full row width.

```tsx
<Item>
  <ItemHeader>
    <ItemTitle>Account</ItemTitle>
    <Typography variant='small'>Updated today</Typography>
  </ItemHeader>

  <ItemContent>
    <ItemDescription>
      Your account information.
    </ItemDescription>
  </ItemContent>

  <ItemFooter>
    <Typography variant='small'>Free plan</Typography>
  </ItemFooter>
</Item>
```

## Structure

```text
Item
├── ItemHeader
├── ItemMedia
├── ItemContent
│   ├── ItemTitle
│   └── ItemDescription
├── ItemActions
└── ItemFooter
```

You do not need to use every primitive.

## API reference

### `Item`

| Prop | Default | Description |
| --- | --- | --- |
| `variant` | `default` | Border/background variant. |
| `size` | `default` | Spacing and size variant. |
| `className` | — | Additional classes. |
| `...props` | — | React Native `View` props. |

### `ItemMedia`

| Prop | Default | Description |
| --- | --- | --- |
| `variant` | `default` | Media presentation: `default`, `icon`, or `image`. |
| `className` | — | Additional classes. |

### Other primitives

`ItemContent`, `ItemActions`, `ItemGroup`, `ItemSeparator`, `ItemTitle`, `ItemDescription`, `ItemHeader`, and `ItemFooter` accept their corresponding native `View`, `Typography`, or `Separator` props.

<Callout>

Use `Item` for repeated rows and settings-style interfaces. Keep the primary action inside `ItemActions` so the content hierarchy remains easy to scan.

</Callout>
