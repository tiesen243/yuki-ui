title: Yuki UI Registry

Yuki UI is a shadcn-style registry for application-level utilities and components.

The registry is split into focused categories so you can install only the pieces your project needs.

## Registry categories

### Authentication

The auth registry provides server authentication, OAuth providers, sessions, access/refresh tokens, and database adapters.

See [Authentication](./auth).

### Components

Web UI components include the Markdown editor, Neovim-style statusline, Open Graph generator, skeleton loading state, toast system, and typography primitives.

See the individual pages under `components/`.

### Hooks

Reusable React hooks for debouncing, form state, immutable updates, and SSR-safe layout effects.

See the individual pages under `hooks/`.

### Libraries

Utilities for environment validation, IDs, safe React contexts, cryptography, Effect-based environment validation, forms, and password hashing.

See the individual pages under `lib/`.

### React Native

Native counterparts for common shadcn primitives, plus native-only components such as Bottom Sheet and Toast.

See the individual pages under `native/`.

## Installation

Every registry-backed page includes both CLI and manual installation instructions. Prefer the CLI when possible because it also resolves declared registry dependencies.
