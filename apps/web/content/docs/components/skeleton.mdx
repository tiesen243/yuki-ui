`Skeleton` is a lightweight loading placeholder for web interfaces. It supports text, circular, and rectangular shapes and three animation modes.

The component is presentation-only: it does not manage loading state. Render it conditionally while the real content is being fetched or prepared.

## Usage

```tsx
import { Skeleton } from '@/components/ui/skeleton'

export function ProfileSkeleton() {
  return (
    <div className='flex items-center gap-3'>
      <Skeleton variant='circular' className='size-10' />
      <div className='flex-1 space-y-2'>
        <Skeleton variant='text' className='max-w-48' />
        <Skeleton variant='text' className='max-w-32' />
      </div>
    </div>
  )
}
```

## Variants

### `rectangular`

The default shape for arbitrary blocks.

```tsx
<Skeleton variant='rectangular' className='h-32 w-full' />
```

### `circular`

Keeps a square aspect ratio and uses a fully rounded shape.

```tsx
<Skeleton variant='circular' className='size-12' />
```

### `text`

Uses a text-like inline element and stretches to the available width.

```tsx
<Skeleton variant='text' className='max-w-sm' />
```

## Animation

The default animation is `shimmer`.

```tsx
<Skeleton animation='shimmer' />
<Skeleton animation='pulse' />
<Skeleton animation='solid' />
```

Use `solid` when motion should be avoided.

## API Reference

### `Skeleton`

| Prop        | Type                                    | Default         |
| ----------- | --------------------------------------- | --------------- |
| `variant`   | `'text' \| 'circular' \| 'rectangular'` | `'rectangular'` |
| `animation` | `'pulse' \| 'shimmer' \| 'solid'`       | `'shimmer'`     |
| `className` | `string`                                | —               |
| `...props`  | `React.HTMLAttributes<HTMLDivElement>`  | —               |

The rendered element is a `span` for `text` and a `div` for `circular` and `rectangular` variants.
