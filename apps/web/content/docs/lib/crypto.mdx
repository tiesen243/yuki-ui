The `crypto` utility provides low-level encoding helpers and a constant-time byte comparison function.

It is intentionally small and dependency-free. These helpers are used by the authentication utilities and are useful anywhere you need predictable hex or base64url encoding around binary data.

## Constant-time comparison

`constantTimeEqual` compares two byte arrays without early-exit comparison based on the first differing byte:

```tsx
import { constantTimeEqual } from '@/lib/crypto'

constantTimeEqual(
  new Uint8Array([1, 2, 3]),
  new Uint8Array([1, 2, 3]),
)
// true
```

The function immediately returns `false` when the input lengths differ.

## Hex encoding

```tsx
const encoded = encodeHex(new Uint8Array([0xde, 0xad]))
// 'dead'

const decoded = decodeHex(encoded)
// Uint8Array([222, 173])
```

`decodeHex` rejects odd-length or invalid strings.

## Base64url encoding

```tsx
const encoded = encodeBase64Url(new Uint8Array([1, 2, 3]))
const decoded = decodeBase64Url(encoded)
```

The encoding uses the URL-safe `-` and `_` characters instead of `+` and `/`.


## API Reference

### `constantTimeEqual`

```ts
constantTimeEqual(a: Uint8Array, b: Uint8Array): boolean
```

### `encodeHex`

```ts
encodeHex(data: Uint8Array): string
```

### `decodeHex`

```ts
decodeHex(data: string): Uint8Array
```

### `encodeBase64Url`

```ts
encodeBase64Url(bytes: Uint8Array): string
```

### `decodeBase64Url`

```ts
decodeBase64Url(encoded: string): Uint8Array
```

`decodeHex` and `decodeBase64Url` throw on malformed input.
