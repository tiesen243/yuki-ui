The native Button uses React Native `Pressable` while reusing the design system button variants and sizes.

> See the [shadcn/ui Button documentation](https://ui.shadcn.com/docs/components/base/button) for the web component API, concepts, and additional examples.

## Usage

```tsx
import { Button } from '@/components/native/button'

<Button onPress={() => console.log('Pressed')}>Continue</Button>
```

### Variants

The button supports `default`, `outline`, `secondary`, `ghost`, `success`, `destructive`, `info`, `warning`, and `link` variants.

```tsx
<Button variant='default'>Default</Button>
<Button variant='secondary'>Secondary</Button>
<Button variant='outline'>Outline</Button>
<Button variant='ghost'>Ghost</Button>
<Button variant='destructive'>Delete</Button>
```

### Sizes

The `size` prop is inherited from the base button variants, so the native component stays aligned with the web design system.

```tsx
<Button size='sm'>Small</Button>
<Button size='default'>Default</Button>
<Button size='lg'>Large</Button>
```

### Disabled state

Use the native `disabled` prop from `Pressable`.

```tsx
<Button disabled>Continue</Button>
```

The component also applies a pressed opacity state while the user is interacting with it.
