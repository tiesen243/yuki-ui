`Editor` is a controlled Markdown editor with two composable views: `EditorInput` for authoring source text and `EditorPreview` for rendering the current Markdown value.

The component keeps the Markdown value outside of the editor and exposes it through `value` and `onValueChange`. The preview is parsed with Marked.js using line breaks, so the same value can be edited and rendered without duplicating state.

## Usage

Use the editor as a controlled component.

```tsx
import { useState } from 'react'

import {
  Editor,
  EditorInput,
  EditorPreview,
} from '@/components/ui/editor'

export function MarkdownEditor() {
  const [value, setValue] = useState('# Hello')

  return (
    <Editor value={value} onValueChange={setValue}>
      <EditorInput />
      <EditorPreview />
    </Editor>
  )
}
```

`EditorInput` and `EditorPreview` consume the value from the parent `Editor` context. They should be rendered inside an `Editor`.

## Input and preview

The editor is intentionally split into two primitives:

- `EditorInput` renders the textarea used to edit Markdown.
- `EditorPreview` parses the current value and injects the resulting HTML into the preview pane.

The preview is regenerated whenever `value` changes.

## Parsing Markdown

The parser is also exported as `parseContent`:

```tsx
import { parseContent } from '@/components/ui/editor'

const html = parseContent('# Hello')
```

The parser uses Marked.js with `breaks: true`. Parse failures return the literal `Error parsing content` string in development-safe usage rather than throwing from the preview component.

## Controlled state

Do not maintain a second internal value when composing the editor. Keep a single source of truth in the parent:

```tsx
const [markdown, setMarkdown] = useState('')

<Editor
  value={markdown}
  onValueChange={setMarkdown}
>
  ...
</Editor>
```

## API Reference

### `Editor`

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | required |
| `onValueChange` | `(value: string) => unknown` | required |
| `className` | `string` | — |
| `children` | `React.ReactNode` | — |
| `...props` | `React.ComponentProps<'div'>` | — |

### `EditorInput`

Accepts standard `div` props and renders the controlled Markdown textarea.

### `EditorPreview`

Accepts standard `div` props and renders the parsed Markdown HTML.

### `parseContent`

```ts
function parseContent(content: string): string
```

This is the exported alias of the internal `parseMarkdown` helper.
