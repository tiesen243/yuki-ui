The native `Separator` is a lightweight visual divider. It supports both horizontal and vertical orientations and uses the project's border color token.

Unlike an interactive component, the separator has no internal state and simply renders a styled native `View`.

See the [shadcn/ui Separator documentation](https://ui.shadcn.com/docs/components/base/separator) for the web component API, concepts, and additional examples.

## Features

- Horizontal and vertical orientations.
- Minimal native `View` implementation.
- Works with arbitrary layout containers.
- Supports custom classes and native view props.

## Usage

```tsx
import { Separator } from '@/components/native/separator'

export function SeparatorExample() {
  return (
    <>
      <View className='gap-4'>
        <Text>Account</Text>
        <Separator />
        <Text>Preferences</Text>
      </View>
    </>
  )
}
```

## Horizontal

The default orientation fills the available width.

```tsx
<Separator />
```

## Vertical

Use `orientation='vertical'` inside a row to create a vertical divider.

```tsx
<View className='h-6 flex-row items-center'>
  <Text>Profile</Text>
  <Separator orientation='vertical' />
  <Text>Settings</Text>
</View>
```

## API Reference

### Separator

| Prop | Type | Default |
| --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `className` | `string` | — |
| `...props` | `React.ComponentProps<typeof View>` | — |

Horizontal separators use `h-px w-full`. Vertical separators use `w-px self-stretch`.
