`createEnv` validates runtime environment variables against Standard Schema definitions and returns a typed environment object.

The utility separates shared, server-only, and client-only variables. On the client, attempts to read a declared server-only variable throw instead of silently exposing the value.

## Usage

```tsx
import { z } from 'zod'

import { createEnv } from '@/lib/create-env'

export const env = createEnv({
  server: {
    DATABASE_URL: z.string().url(),
    AUTH_SECRET: z.string().min(32),
  },
  clientPrefix: 'PUBLIC_',
  client: {
    PUBLIC_API_URL: z.string().url(),
  },
  shared: {
    NODE_ENV: z.enum(['development', 'production', 'test']),
  },
  runtimeEnv: {
    DATABASE_URL: process.env.DATABASE_URL,
    AUTH_SECRET: process.env.AUTH_SECRET,
    PUBLIC_API_URL: process.env.PUBLIC_API_URL,
    NODE_ENV: process.env.NODE_ENV,
  },
})
```

## Server and client variables

Server keys must not start with `clientPrefix`. Client keys must start with the configured prefix. This is enforced by the TypeScript types before runtime validation.

## Runtime environment mapping

Pass client variables explicitly in `runtimeEnv` rather than spreading the entire `process.env` object into browser code. This keeps server-only variables out of the client bundle.

## Derived values

Use `deriveEnv` to create values that depend on already validated variables:

```tsx
const env = createEnv({
  shared: {
    NODE_ENV: z.string(),
  },
  server: {},
  clientPrefix: 'PUBLIC_',
  client: {},
  runtimeEnv: {
    NODE_ENV: process.env.NODE_ENV,
  },
  deriveEnv: (env) => ({
    IS_PRODUCTION: env.NODE_ENV === 'production',
  }),
})
```

## Empty strings and skipped validation

`emptyStringAsUndefined` converts empty runtime values into `undefined` before validation. `skipValidation` bypasses validation but keeps the typed proxy.

Use `skipValidation` sparingly; it removes the runtime guarantee that this utility is designed to provide.

## API Reference

### `createEnv`

```ts
createEnv(options): TResult & TDeriveEnv
```

| Option                   | Description                                                                              |
| ------------------------ | ---------------------------------------------------------------------------------------- |
| `isServer`               | Override automatic server/client detection. Defaults to `typeof window === 'undefined'`. |
| `shared`                 | Schemas available in both environments.                                                  |
| `server`                 | Server-only schemas.                                                                     |
| `clientPrefix`           | Required prefix for client variable names.                                               |
| `client`                 | Client-only schemas.                                                                     |
| `runtimeEnv`             | Runtime values that are validated.                                                       |
| `deriveEnv`              | Optional function that derives extra values from validated env data.                     |
| `emptyStringAsUndefined` | Converts `''` to `undefined` before validation.                                          |
| `skipValidation`         | Skips runtime validation.                                                                |

The returned object is a proxy. Reading a server-only key from the client throws an explicit error.
