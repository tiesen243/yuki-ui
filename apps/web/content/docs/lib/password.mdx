`Password` is a server-side password hashing utility backed by Node's `scrypt` implementation.

It generates a random salt for every password, derives a key with configurable scrypt parameters, and stores the result in a compact `salt:hash` representation. Verification compares the derived bytes with the stored key using a constant-time comparison.

## Usage

```tsx
import { Password } from '@/lib/password'

const password = new Password({
  secret: process.env.PASSWORD_SECRET,
})

const hash = await password.hash('correct horse battery staple')
const valid = await password.verify(
  hash,
  'correct horse battery staple',
)
```

Keep the optional `secret` outside the user database. It acts as an application-level secret mixed into the password before derivation.

## Configuration

```tsx
const password = new Password({
  secret: process.env.PASSWORD_SECRET,
  dkLen: 64,
  N: 16_384,
  r: 8,
  p: 1,
  maxmem: 32 * 1024 * 1024,
})
```

The defaults follow the constructor values in the registry source.

## Hash format

A hash is stored as:

```text
<hex salt>:<hex derived key>
```

`verify` returns `false` for malformed hashes rather than throwing.


## API Reference

### `Password`

```ts
new Password(options?)
```

| Option | Default |
| --- | --- |
| `secret` | `''` |
| `dkLen` | `64` |
| `N` | `16384` |
| `r` | `8` |
| `p` | `1` |
| `maxmem` | `32 * 1024 * 1024` |

### `hash`

```ts
hash(password: string): Promise<string>
```

Generates a random 16-byte salt and returns a `salt:derivedKey` string.

### `verify`

```ts
verify(hash: string, password: string): Promise<boolean>
```

Returns `false` when the hash is malformed or the derived key does not match.
